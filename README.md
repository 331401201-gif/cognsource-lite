# 思维源体 · 随身版

中台的手机简化版（安卓）。数据全部存在手机里，用阿里云百炼的通义千问整理、转写、看图和问答。

- 记一下：文字、口述、拍照 / 相册、开会录音（不限时长，每 4 分钟自动切段转写）
- 自动整理：标题、概括、待办和时间；明确要做的直接进待办，拿不准的进「等你确认」
- 计划：说目标和截止日，AI 拆成按天的步骤
- 提醒：系统闹钟排程，关掉 App、重启手机后照样响；每天早上一条简报
- 问问：只根据自己的记录回答，标出处
- 设置：模型密钥和档位、提醒时间、权限检查（含 vivo 后台设置入口）、打码、导出 / 恢复备份

结构：`app/src/main/assets/www` 是界面（纯 HTML/JS，不需要编译），`app/src/main/java` 是安卓外壳（联网、闹钟、录音、权限）。
推送到 main 分支后，GitHub Actions 自动打包 APK，发布在 Releases。

本地预览界面：`test/mock_native.js` 是假的原生桥和假模型，配合 Playwright 跑主流程。
